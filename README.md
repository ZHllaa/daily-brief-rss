## 发布范围与更新

本仓库只包含原创简报、来源链接、授权资料图片、分享版 PDF 和字体许可。无私人设置、账户凭据、设备标识或笔迹数据。

GitHub Pages 从 main 分支的 /docs 目录发布。新一期审核、排版和验证完成后，将生成的 docs/ 文件提交到同一分支。保留旧刊文件和稳定 GUID；不只改日期重复发行。生成工具保留在发布工作区，不在此公开。

照片不是当前新闻现场，各自作者、日期及许可见图注。字体许可见 docs/licenses/fonts.txt。robots.txt 仅请求搜索引擎不索引，不构成访问控制。
